"AJOU NINJA"는 증강 현실(AR) 기술을 활용하여 플레이어가 직접 닌자가 되어 마을을 침략하는 몬스터들과 싸우는 액션 게임입니다. 이 게임은 플레이어의 주변 환경을 가상 무대로 바꾸어, 실제 공간에서 몰입감 있게 전투를 즐길 수 있습니다.

- **주요 특징**:
  - **AR 기반의 실감 나는 전투**: 실제 주변 환경을 게임 내 배경으로 활용하여, 플레이어가 마치 현실에서 직접 싸우는 듯한 경험을 제공합니다.=
  - **스테이지 기반 진행**: 각 스테이지는 특정 목표나 보스를 클리어해야 하며, 레벨이 올라갈수록 도전적인 난이도를 제공합니다.

- **목표**: 마을을 침략하는 모든 몬스터들을 물리치고, 최종 보스를 처치하여 마을의 평화를 되찾는 것이 게임의 최종 목표입니다.
